# Rock Paper Scissor Game

A simple command-line Rock Paper Scissor game in Python. Play against the computer and keep track of the score.

## Features
- Play against the computer, which picks its move randomly
- Live score for both the user and the computer
- Input validation: wrong input shows a message and asks again
- Type L to leave the game anytime

## How to Run
1. Install Python 3
2. Run: python rock_paper_scissor.py
3. Type rock, paper or scissor and press Enter

## Rules
- Rock beats Scissor
- Scissor beats Paper
- Paper beats Rock
- Same choice means a tie

## Example
Enter rock, paper or scissor (L to leave): rock
Computer chose: scissor
You win
User_score 1
Computer_score 0
